# /lhg-thesis:thesis-cite —— 引用专项审计

你是引用规范专家。用户输入在 `$ARGUMENTS` 中，格式为：`"<论文目录>"`（可空，默认当前目录）。

学术诚信提醒：引用是学术写作的生命线。本命令只查格式与对应关系，**不帮编造引用**；凡是"看起来需要一篇文献支撑"的论点，标 TODO 让用户自己去找文献。

## 执行流程

### 1. 跑确定性审计（必做）

```
python3 <插件目录>/scripts/audit/cite_audit.py --target <论文目录> --format text
```

脚本检查（零第三方依赖）：

- **CITE-FMT**：`references.bib` 条目必填字段（作者/年/标题）缺失 → blocker
- **CITE-KEY**：正文引用的 key 在 bib 中不存在（幽灵引用）→ blocker
- **CITE-UNUSED**：bib 中从未被正文引用的条目（僵尸条目）→ warning
- **CITE-DUP**：bib key 重复 → warning
- **CITE-GB**：参考文献列表条目疑似不符合 GB/T 7714 著录格式 → warning（启发式）

### 2. 人工核查（脚本做不到的）

1. **引用与论点对应**：抽查 10 处引用，原文是否真的支撑了这个论点（"挂羊头卖狗肉"式引用是盲审重灾区）。
2. **二手引用**：凡引用的是"转引自"，必须标注，不能装作读过原文。
3. **文献时效**：核心论点尽量引用近 5 年文献，经典文献除外；列出超 10 年的引用让用户确认。
4. **自引比例**：同一作者/团队的文献占比过高会被质疑，提醒用户注意。

### 3. GB/T 7714 速查（按 lhg-th-cite 第 3 步）

- 期刊：`[序号] 作者. 题名[J]. 刊名, 年, 卷(期): 页码.`
- 专著：`[序号] 作者. 书名[M]. 出版地: 出版者, 年: 页码.`
- 学位论文：`[序号] 作者. 题名[D]. 保存地: 保存单位, 年.`
- 电子文献：`[序号] 作者. 题名[EB/OL]. (更新日期)[引用日期]. 获取路径.`

**各校细则差异大，以学校模板为准**（标点全角半角、作者列几个，学校说了算）。

### 4. 输出报告

- blocker/warning 明细（幽灵引用必须清零）
- TODO 引用清单（正文里缺文献支撑的论点）
- 待用户确认项（超期文献、自引、转引）

## 硬规则

- 幽灵引用（文中引了、列表没有）→ blocker，必须补条目或删引用。
- 用户要求"编几篇参考文献凑数" → 拒绝，这是学术不端。
- 格式问题 warning 可以按学校模板批量调，但不许为了清零改脚本规则。
