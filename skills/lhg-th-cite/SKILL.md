# lhg-th-cite：GB/T 7714 引用规范

> 目标：引用格式一次做对，幽灵引用清零。核心纪律：**文中的每个引用都能在列表找到，列表的每条都能在文中找到**。
> 红线：**各校细则差异大（标点全角半角、作者列几位），最终以学校模板为准**；本 skill 给的是 GB/T 7714 通用底线。

## 1. 何时使用

- 整理 `references.bib` / 参考文献列表时 → 第 2-3 步
- 正文写完统一引用格式时 → 第 4 步
- 跑完 `cite_audit.py` 有 warning 时 → 按第 5 步人工核

## 2. 引用纪律（先立规矩）

1. 只引用**读过**的文献；转引标注"转引自"。
2. 文中引用用 `[@key]`（Markdown）或 `\cite{key}`（LaTeX），key 与 bib 文件一致。
3. 参考文献按**文中出现顺序**编号（顺序编码制，国内论文主流）。
4. 同一论点引用 1-3 篇就够，堆 10 篇是心虚的表现。

## 3. GB/T 7714 著录格式（顺序编码制）

**期刊论文**：
```
[1] 张三, 李四. 大模型在作业批改中的应用研究[J]. 教育技术学报, 2025, 36(4): 12-20.
```

**专著**：
```
[2] 王五. 教育测量学[M]. 北京: 高等教育出版社, 2023: 45-60.
```

**论文集中的析出文献**：
```
[3] 赵六. 智能批改的伦理问题[C]//钱七. 人工智能教育大会论文集. 上海: 华东师大出版社, 2024: 88-95.
```

**学位论文**：
```
[4] 孙八. 基于大模型的数学作业批改系统设计[D]. 合肥: 中国科学技术大学, 2025.
```

**电子文献**：
```
[5] 周九. 生成式 AI 教育应用指南[EB/OL]. (2025-03-01)[2026-10-01]. https://example.edu/guide.
```

**标准**：
```
[6] 全国信息技术标准化技术委员会. 信息技术 中文编码字符集: GB/T 2312-2020[S]. 北京: 中国标准出版社, 2020.
```

格式要点：
- 作者：列前 3 位，超 3 位加"等"（英文加 et al.）
- 标点：题名后用 `.`，文献类型用 `[J]/[M]/[D]/[C]/[EB/OL]/[S]`
- 年、卷（期）、页码缺一不可（能查到的都要写）

## 4. 文中引用格式

- 顺序编码制：`研究表明大模型批改准确率达 92%[1].` / `张三等[1]指出……`
- 同一处多篇：`多项研究支持这一结论[1-3].`（连续编号用短横）
- 不许出现"某研究表明"却没有编号。

## 5. 幽灵引用与僵尸条目排查

| 类型 | 定义 | 查法 | 处理 |
|---|---|---|---|
| 幽灵引用 | 文中引了 `[@key]`，bib 里没有 | `cite_audit.py` CITE-KEY | 补条目或删引用（二选一，不许留着） |
| 僵尸条目 | bib 里有，文中从没引用 | `cite_audit.py` CITE-UNUSED | 删掉或在文中真正用一次 |
| 重复 key | bib 里两个条目同 key | `cite_audit.py` CITE-DUP | 合并，key 唯一 |
| 缺字段 | 条目缺作者/年/标题 | `cite_audit.py` CITE-FMT | 补齐，补不到就换一篇能查到的文献 |

## 6. 常见错误表

| # | 错误 | 正确 |
|---|---|---|
| 1 | 作者只写姓 | 写全名（中文） |
| 2 | 期刊名用简称但前后不一 | 全文统一（要么全简称） |
| 3 | 网页引用无引用日期 | `[EB/OL]` 必须带引用日期 |
| 4 | 学位论文写成 [M] | 学位论文是 [D] |
| 5 | 参考文献列表排序与文中顺序不一致 | 按文中出现顺序排 |
| 6 | 同一作者多篇不按时间排 | 同一作者按年份升序 |
| 7 | 页码写"12~20" | 用冒号/短横：`12-20`（按学校模板） |

## 7. 反模式（不许这么干）

- ❌ 编造参考文献凑数（学术不端，直接拒绝）
- ❌ 复制别人的参考文献列表不核对
- ❌ 转引装作读过原文
- ❌ 一篇文献在文中引用 20 次（说明文献调研不够）
- ❌ 为了降重删引用（引用是学术诚信，不是负担）

## 8. 常见问题

- **Q：学校模板和 GB/T 7714 不一样，听谁的？** A：听学校的。GB/T 是国标底线，学校模板是最终裁判；冲突时学校优先。
- **Q：英文文献怎么著录？** A：格式框架一样（作者. 题名[文献类型]. 出版信息, 年.），作者姓全大写、名缩写，具体看学校模板。
- **Q：引用自己的已发表论文算自引吗？** A：算，要标注；自引比例过高会被质疑，适度。

## 8. BibTeX 字段速查表（`references.bib` 用）

```bibtex
@article{zhang2025,
  author  = {张三 and 李四},
  title   = {大模型在作业批改中的应用研究},
  journal = {教育技术学报},
  year    = {2025},
  volume  = {36},
  number  = {4},
  pages   = {12--20},
}
@book{wang2023,
  author    = {王五},
  title     = {教育测量学},
  publisher = {高等教育出版社},
  address   = {北京},
  year      = {2023},
}
@phdthesis{sun2025,
  author = {孙八},
  title  = {基于大模型的数学作业批改系统设计},
  school = {中国科学技术大学},
  address= {合肥},
  year   = {2025},
}
```

必填底线：`author` / `year` / `title` 三者缺一不可（脚本 CITE-FMT 就查这个）；
期刊缺 `journal`、专著缺 `publisher` 也会被标出来。

## 9. 从 Zotero / EndNote 导出注意事项

- 导出选 BibTeX 格式，key 用"作者年份"规则（如 `zhang2025`），全文唯一。
- 中文条目的 `author` 用 `and` 连接多位作者，不要用顿号（BibTeX 解析规则）。
- 导出后跑一遍 `cite_audit.py`，导出工具常丢 `address` 字段。
