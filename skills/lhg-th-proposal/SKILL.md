# lhg-th-proposal：开题与大纲

> 目标：把"想写点什么"收敛成"可回答、可验证"的研究问题，再搭出不缺件的大纲。
> 核心纪律：**问题没收敛不开题，大纲没定不写正文**。

## 1. 何时使用

- 用户只有模糊想法（"想写 AI+教育"）→ 从第 2 步开始
- 用户已有题目 → 从第 3 步验证题目是否成立
- 大纲被导师打回 → 按第 5 步自查缺件

## 2. 研究问题收敛五问

一次问 1-2 个，先开放后收敛：

1. **领域**：具体哪个细分方向？（"AI+教育"→"大模型在初中数学作业批改中的应用"）
2. **问题**：你想回答的一个具体问题是什么？（一句话，能加问号）
3. **数据**：你手里有什么数据/案例能回答它？（没有数据=空对空，趁早换题）
4. **方法**：打算用什么方法？（实验/问卷/案例/文献计量，方法要配得上问题）
5. **边界**：什么不研究？（写出三条"本文不涉及"，防止写散）

收敛标准：能用一句话说出"本文研究 X，在 Y 条件下，用 Z 方法，回答 W 问题"。

## 3. 开题四件套

| 件 | 写什么 | 常见病 |
|---|---|---|
| 研究背景 | 为什么这个问题值得研究（现实痛点+理论缺口，各一段） | 背景写成行业报告，与问题脱节 |
| 研究问题 | 2-4 个层层递进的子问题 | 问题太多太散，或问题太大答不了 |
| 研究方法 | 用什么方法、为什么这个方法合适 | 方法与问题不匹配（如用问卷回答"为什么"） |
| 创新点 | 可能的创新，诚实写"预期"，不许包装成"已实现" | 把"工作量"当"创新点" |

## 4. 文献初筛纪律

- 只整理**真正读过**的文献；没读过的放"待读清单"，不许出现在开题报告的引用里。
- 每篇文献记三行：研究问题、方法、与本研究的差距（一句话）。
- 文献综述不是"文献罗列"：按主题/方法/观点分组，组内对比，组间指出缺口——缺口就是你的研究问题。

## 5. 三级大纲模板

```
第 1 章 绪论
  1.1 研究背景与意义
  1.2 国内外研究现状（→第 2 章展开，这里只给地图）
  1.3 研究内容与方法
  1.4 论文组织结构
第 2 章 文献综述与理论基础
  2.1 相关概念界定
  2.2 理论基础
  2.3 国内外研究现状（分组综述+评述）
第 3 章 研究设计/方法
  3.1 研究框架
  3.2 数据来源与处理
  3.3 研究方法
第 4 章 结果与分析
  4.1 描述性结果
  4.2 核心发现（按研究问题组织，一问一节）
第 5 章 结论与展望
  5.1 主要结论（回答绪论的问题，首尾呼应）
  5.2 创新点
  5.3 不足与展望
参考文献
附录（问卷/代码/原始数据说明）
```

每节标注：要回答的问题、预计字数、需要的数据/文献。标不出来=这节没想清楚。

## 6. 完整性门控（大纲评审清单）

- [ ] 摘要、绪论、文献综述、研究方法、结果分析、结论、参考文献，七件齐了？
- [ ] 研究问题在绪论提出、在结论回答（首尾呼应）？
- [ ] 每章都有明确的研究问题归属，没有"为了凑字数"的章节？
- [ ] 方法配得上问题，数据支撑得起方法？
- [ ] 创新点诚实（"预期"vs"已实现"分得清）？

## 7. 反模式（不许这么干）

- ❌ 题目大到"论人工智能"还觉得没问题
- ❌ 没数据硬开题，指望"写的时候再说"
- ❌ 文献综述=文献堆砌，没有分组与评述
- ❌ 创新点写"首次将 A 用于 B"但不论证为什么该用
- ❌ 大纲跳过方法论章节，直接写结果
- ❌ 把开题报告的"预期创新"写成已完成时

## 8. 常见问题

- **Q：导师说题目太大，怎么收小？** A：加限定词三选一：限定对象（初中而非教育）、限定场景（作业批改而非教学）、限定方法（案例而非普适规律）。
- **Q：实在找不到数据怎么办？** A：三条路：换有数据的题目、用公开数据集、做小规模一手调研。没有第四条路（编数据是红线）。
- **Q：开题要写多少字？** A：看学校要求，通常 3000-5000 字。字数不够多半是问题没收敛，不是写得少。

## 9. 选题灵感从哪来

- 导师的在研课题（最稳：数据、方法、文献都有人带）
- 实习/工作中遇到的真问题（最有料：痛点真实）
- 文献的"未来工作"节（最学术：缺口现成）
- 不要从"感觉这个很火"出发：火=难出新意，且你大概率没数据
- 往届优秀论文的题目库：看 3 届本校优秀论文，找"可模仿的结构"，不抄题目
- 开题答辩 PPT 只讲三页：问题是什么、打算怎么做、预期得到什么——评委没耐心听第四页
- 开题被质疑很正常：把质疑记下来，它就是你第一章要回答的问题

## 10. 开题报告写作模板（3000-5000 字）

```
一、选题背景与意义（800 字）
    现实痛点一段 + 理论缺口一段 + 研究意义两句
二、国内外研究现状（1200 字）
    按 2-3 个主题分组综述，每组结尾一句评述
三、研究内容与方法（800 字）
    研究问题列表 + 技术路线图（文字版） + 方法选择理由
四、创新点（300 字）
    预期创新 2-3 条，诚实标注"预期"
五、进度安排（200 字）
    按月列，留 1 个月 buffer 给返工
六、参考文献（20-30 篇，全部读过）
```

## 10. 导师沟通清单（开题前）

- [ ] 题目收敛到一句话，导师点头
- [ ] 数据来源导师认可（别自己闷头找）
- [ ] 方法选择问过导师意见
- [ ] 开题报告提前 3 天发给导师，不许开题当天才给

## 11. 自检与反馈

**质检门**：
- [ ] 一句话能说清研究问题？
- [ ] 开题四件套齐了？创新点诚实？
- [ ] 三级大纲每节都标了问题/字数/数据需求？
- [ ] 完整性门控全过？

**标准冒烟用例**：拿一个模糊题目（如"短视频对青少年的影响"）走一遍五问，输出应收敛到带限定词的具体问题。

**发现问题**：到本仓库提 issue（标题前缀 `[lhg-th-proposal]`），描述：题目、大纲、哪条门控没过。
